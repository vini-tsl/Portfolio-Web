## Sobre

Este projeto é o meu **portfólio pessoal**, desenvolvido para apresentar minha trajetória na área de tecnologia, meus principais projetos, conhecimentos técnicos e formas de contato.

Além de funcionar como uma apresentação profissional, o projeto também serve como espaço para aplicar e demonstrar meus conhecimentos em desenvolvimento frontend.

## Características

* Interface moderna
* Design responsivo
* Interface desenvolvida com Tailwind CSS
* Animações utilizando Framer Motion
* Efeitos de digitação
* Componentização com React
* Build otimizado com Vite
* Seção de projetos
* Seção de tecnologias
* Área de contato

## Executando localmente

### 1. Clone o projeto

```bash
git clone https://github.com/vini-tsl/portfolio.git
cd portfolio
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Execute o ambiente de desenvolvimento

```bash
npm run dev
```

O Vite disponibilizará a aplicação localmente.

### 4. Build de produção

```bash
npm run build
```

### 5. Preview da build

```bash
npm run preview
```

### 6. Verificação de código

```bash
npm run lint
```
